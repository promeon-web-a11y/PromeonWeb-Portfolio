# CLAUDE.md

## 適用範囲

このファイルと `DESIGN.md` は **このフォルダ（`samples/01-north-reform/`）だけ** に適用される制作ルールです。
対象は「ノースリフォーム」（架空クライアント）の内装リフォーム Webサイト（`index.html`）1件のみ。

- このフォルダの外（`po-forio` のポートフォリオ本体 `index.html`、他の `samples/*`、`_ds/`）には適用しません。
- 参照するデザインシステムは **同じフォルダの `DESIGN.md`**。`../../_ds/modernist-*` は別プロジェクト（ポートフォリオ本体）のものなので使いません。

## サイト概要

- 札幌市・江別市・北広島市・石狩市ほか札幌近郊の、個人事業主による内装リフォーム／内装修繕サイト。
- 目的：初めて知った人が安心して「相談」できること（契約ではなく相談がゴール）。
- 軸：**清掃・整理整頓 × 代表本人の直接対応 × 小さな工事対応 × 札幌地域密着**。
- 静的サイト（ビルドなし・素の HTML / CSS / JS）。単一 `index.html` に `<style>` / `<script>` を内包。

## 作業ルール

### デザイン変更
1. **デザインを変更する前に、必ず同じフォルダの `DESIGN.md` を読む。**
2. **`DESIGN.md` に存在しない 色 / radius / shadow / font-size / breakpoint をむやみに追加しない。**
   必要な場合は、先に `DESIGN.md` を更新し、その意図を説明してから使う。
3. **既存のデザインシステム（`DESIGN.md` のトークン）を優先する。** 独自の値やパターンをその場で発明しない。
4. `DESIGN.md` の「§5 Grid」「§12 Anti-AI Design Rules」に反する構成にしない
   （3カラムカードの連続、全セクション中央揃え、box-shadow 乱用、巨大 radius、装飾目的のアイコン、
   意味のない英語ラベル、pill 乱用、全要素 fade-in、情報の詰め込み 等）。

### 変更の安全性
5. **依頼されていないコンテンツを勝手に削除・改変しない。** 文言・セクション・画像スロットの削除は明示の指示があるときだけ。
6. **既存機能を壊さない**（ハンバーガーメニュー、スクロールインアニメーション、お問い合わせフォームの確認パネル、
   画面下固定 CTA バー、`#` アンカーナビゲーション）。変更後に動作を確認する。
7. **大きな変更の前に、現在の `index.html` の構造・マークアップ・CSS を読んで把握する。** 影響範囲を確認してから着手する。

### 表示・品質
8. **PC / Tablet / Mobile の3表示を必ず考慮する**（`DESIGN.md` §10 の breakpoint・余白・文字サイズ・レイアウト変更ルールに従う）。
9. **日本語の改行を確認する**（`DESIGN.md` §11）。不自然な折り返し、行末の1〜2文字の孤立、見出しの割れを
   各ブレークポイントで目視チェック。本文の横幅を広げすぎない、本文を小さくしすぎない。

### その他
10. ビルドツール・フレームワークを勝手に導入しない。
11. 変更は最小差分で。既存のコード様式（クラス命名、トークンの使い方、コメント密度）に合わせる。
12. 写真は差し替え前提のプレースホルダー。`<img>` の雛形コメントと推奨比率（`DESIGN.md` §6）を残す。
