service/ — 事業内容ページの各サービス写真
比率 3:2 / 推奨 1600×1067px / 目安 200〜300KB。共通ルールは ../README.md を参照。

service-01-pruning.webp … 庭木の剪定
  脚立の上や木のそばで剪定している職人の作業風景、または鋏を持つ手元のアップ。切り整えた枝の様子が分かると良い。

service-02-felling.webp … 伐採・抜根
  チェーンソーやロープを使った伐採作業、または撤去後の切り株・掘り取りの様子。ヘルメット等の装備が写っていると信頼感が出る。

service-03-garden.webp … 庭づくり・庭のリフォーム
  リフォーム後の歩きやすい庭（園路・砂利・低木）。生活感のある実際の住宅の庭で「施工後」の状態を。

service-04-exterior.webp … 外構・エクステリア
  アプローチ・フェンス・花壇・砂利敷きなど住まい周りの外構。完成直後の整った状態を、正面よりやや斜めから。

service-05-annual.webp … 年間庭園管理
  定期巡回で剪定・除草・清掃をしている作業風景。道具や軽トラを含め、同じ庭を継続管理している雰囲気で。

service-06-business.webp … 法人・施設向け植栽管理
  マンション共用部や施設の植栽を管理している様子。人の動線や建物が入り、住宅とは違う規模感が伝わる1枚。

service-07-winter.webp … 冬囲い
  雪の前の冬囲い（支柱・縄がけ）の作業、または囲いが済んだ庭木。北海道らしい雪景色・冬の光があると季節感が出る。
