# CLAUDE.md

## 適用範囲

このファイルと `DESIGN.md` は **このフォルダ（`samples/02-hokusuien/`）だけ** に適用される制作ルールです。
対象は「株式会社北翠園」（架空クライアント）の造園・庭園管理・外構工事の Webサイト。
**Standardプラン想定の5ページ構成**（`index.html` / `service.html` / `works.html` / `about.html` / `company.html`）＋共通の `assets/style.css` `assets/app.js`。

- このフォルダの外（`po-forio` のポートフォリオ本体 `index.html`、`samples/01-north-reform/` ほか他の `samples/*`、`_ds/`）には適用しません。
- 参照するデザインシステムは **同じフォルダの `DESIGN.md`**。`../../_ds/modernist-*` は別プロジェクト（ポートフォリオ本体）のものなので使いません。`samples/01-north-reform/DESIGN.md` とも別系統です（色・フォント・トークンを混在させない）。

## サイト概要

- 北海道札幌市を拠点に、札幌近郊（石狩市・江別市・北広島市ほか）で造園・庭園管理・外構工事を行う、従業員約20名・創業1989年の会社を想定。
- 顧客は一般住宅（40〜70代の戸建て）と、マンション管理会社・不動産会社・店舗・病院・福祉施設・企業・公共施設などの法人。
- 目的（優先順）：①初めて見た人への安心感 ②何を依頼できる会社か分かること ③地域密着・長年営業 ④スマホでの見やすさ ⑤問い合わせのしやすさ。次点で 施工事例／スタッフ・人柄／地域活動／SEO／適度なアニメーション。**ゴールは契約ではなく「相談」。**
- サイトが最終的に与えたい印象：「昔から地域にあるちゃんとした会社」「職人の雰囲気が分かって安心」「剪定くらいでも相談できそう」「一度庭を見てもらおうかな」。価格の安さより「安心して長く付き合える造園会社」。
- 核となる訴求：安心感 / 人柄 / 地域とのつながり / 施工力。地域密着・長年の信頼・人とのつながり・職人の顔が見える・庭を長く守る。
- メインコピー：**「この街の緑を、これからも。」**
- 静的サイト（ビルドなし・素の HTML / CSS / JS）。CSS/JS は `assets/` の共通1本ずつに集約。

## 作業ルール

### デザイン変更
1. **デザインを変更する前に、必ず同じフォルダの `DESIGN.md` を読む。**
2. **`DESIGN.md` に存在しない 色 / radius / shadow / font-size / breakpoint をむやみに追加しない。**
   必要な場合は、先に `DESIGN.md` を更新し、その意図を説明してから使う。
3. **既存のデザインシステム（`DESIGN.md` のトークン）を優先する。** 独自の値やパターンをその場で発明しない。
4. `DESIGN.md` の「§5 Grid & Page Composition」「§9 Animation」「§12 Anti-AI Design Rules」に反する構成にしない
   （3カラムカードの連続、全セクション中央揃え、box-shadow 乱用、巨大 radius、装飾目的のアイコン、
   意味のない英語ラベル、pill 乱用、全要素 fade-in、セクション/ページごとに違うアニメーション、
   グラデーション、明朝の全面採用、情報の詰め込み 等）。
5. 色はブランド緑1系統のみ。CTA文言は「庭のお悩みを相談する」中心で、営業色の強い表現（「今すぐ申し込む」「限定」「キャンペーン」）・価格訴求・感嘆符の多用をしない。

### 複数ページの一貫性
6. **ヘッダー / フッター / 画面下固定 CTA バーは全ページで同一マークアップ。** どれか1ページで変えたら5ページすべてに反映する。ナビの現在地は `aria-current="page"`。
7. **CSS / JS は `assets/style.css` `assets/app.js` の共通1本ずつ。** ページ個別の `<style>` `<script>` を足さない（ページ固有の微調整も共通CSSにクラスで定義）。
8. 各ページの `<title>` `<meta name="description">` `<link rel="canonical">` はページ内容に合わせて個別に。全ページ `robots: noindex`（サンプルのため）。ページ間リンク（パンくず的な導線・セクション末の「◯◯を見る →」）を必ず用意する。

### 変更の安全性
9. **依頼されていないコンテンツを勝手に削除・改変しない。** 文言・セクション・画像スロットの削除は明示の指示があるときだけ。
10. **既存機能を壊さない**（ハンバーガーメニュー、スクロールインアニメーション、FV演出、お問い合わせフォームの確認パネル、
    画面下固定 CTA バー、FAQ アコーディオン、`#` アンカーナビゲーション）。変更後に動作を確認する。
11. **大きな変更の前に、現在の HTML / `assets/style.css` の構造・マークアップ・CSS を読んで把握する。** 影響範囲を確認してから着手する。

### 表示・品質
12. **PC / Tablet / Mobile の3表示を必ず考慮する**（`DESIGN.md` §10）。個人客はスマホが多い前提で、文字サイズ・改行・写真サイズ・問い合わせボタン・メニュー・電話・LINE の使いやすさを最優先で確認。
13. **日本語の改行を確認する**（`DESIGN.md` §11）。不自然な折り返し、行末の1〜2文字の孤立、見出しの割れを各BPで目視チェック。特に FV コピー「この街の緑を、これからも。」。
14. **写真は「人が写ったもの」を施工写真と同量以上に**（`DESIGN.md` §6）。完成した庭に偏らせない。
15. SEOキーワード（札幌 造園／剪定／伐採／庭 リフォーム／冬囲い／植栽管理 等）は `title` `meta`・見出し・本文に自然な範囲で織り込む。不自然な羅列にしない。

### その他
16. ビルドツール・フレームワークを勝手に導入しない。
17. 変更は最小差分で。既存のコード様式（クラス命名、トークンの使い方、コメント密度）に合わせる。
18. 写真は差し替え前提のプレースホルダー。`<img>` の雛形コメントと推奨比率（`DESIGN.md` §6）を残す。電話番号・LINE URL・Googleマップ・フォーム送信先はダミー。本番前に接続が必要。
19. ポートフォリオ本体（`../../index.html`）の 02 番カードの表示テキスト（会社名・業種・説明・ページ数等）は、まだ「佐倉税理士事務所」のまま。北翠園への差し替えは別途の指示で行う。このフォルダの作業では触らない。
